# Лайки

**Как поставить лайк?**

Есть два способа:

1. **Через контекстное меню:** Нажмите ПКМ на пользователя или его сообщение -> `Приложения` -> `Поставить лайк`.
2. **Через команду:** `/like user:@пользователь`.

{% hint style="warning" %}
Одному и тому же человеку можно ставить лайк не чаще, чем раз в 3 дня.
{% endhint %}

**Новая возможность: Лайк в ответ**

Когда кто-то ставит вам лайк, вы получаете уведомление в ЛС. Теперь в этом уведомлении есть кнопка **"Лайкнуть в ответ"**, позволяющая мгновенно поблагодарить пользователя, не дожидаясь окончания вашего личного кулдауна на него.

**Команды**

| Команда                            | Описание                                                                                 |
| ---------------------------------- | ---------------------------------------------------------------------------------------- |
| `/like <user>`                     | Поставить лайк пользователю через слеш-команду.                                          |
| `/leaderboard <category> [period]` | Показать рейтинг самых "залайканных" пользователей за все время, за неделю или за месяц. |
