# Липкие сообщения

Этот модуль позволяет создавать сообщения, которые автоматически переотправляются и всегда остаются последними в канале во время периодов неактивности.

**Как это работает?**

1. **Настройка:** Администратор создает "липкое" сообщение для определенного канала.
2. **Работа:** Когда обычный пользователь отправляет сообщение в этот канал, бот запускает таймер неактивности (по умолчанию 5 секунд).
3. **Переотправка:** Если в течение этого времени в канале не появляется новых сообщений, бот удаляет свое старое "липкое" сообщение и отправляет его заново, тем самым "приклеивая" его к низу чата. Если же кто-то пишет, пока таймер активен, он сбрасывается.

{% hint style="info" %}
Система работает через вебхуки, что обеспечивает стабильность и предотвращает "призрачные" сообщения, которые могут остаться, если у бота временно пропадают права на удаление.
{% endhint %}

**Настройка модуля**

Для доступа к панели управления используйте команду `/settings sticky`.

**Панель управления позволяет:**

* **Включить/Выключить модуль:** Глобально активировать или деактивировать систему на всем сервере.
* **Добавить сообщение:** Создать новое липкое сообщение для канала через мощный редактор.
* **Редактировать сообщение:** Изменить текст, эмбед и другие параметры уже существующего "липучки".
* **Удалить сообщение:** Убрать липкое сообщение из одного или нескольких каналов.
* **Настройки:** Изменить задержку неактивности — время в секундах (от 3 до 300), которое бот ждет перед переотправкой сообщения.

**Редактор сообщений**

При добавлении или редактировании сообщения вам будет доступен тот же мощный редактор, что и в модуле "Приветствия", позволяющий создавать сообщения с текстом, эмбедами, изображениями и плейсхолдерами.

***

**Плейсхолдеры (Переменные)**

Вы можете использовать переменные сервера в тексте и эмбедах ваших липких сообщений.

| Плейсхолдер           | Описание                         |
| --------------------- | -------------------------------- |
| `{guild.id}`          | ID сервера                       |
| `{guild.name}`        | Название сервера                 |
| `{guild.icon}`        | Ссылка на иконку сервера         |
| `{guild.memberCount}` | Количество участников на сервере |
| `{guild.createdAt}`   | Дата создания сервера            |
