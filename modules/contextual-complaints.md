# Контекстные жалобы

### Для пользователей

**Как подать жалобу?**

Вы можете сообщить о нарушении тремя удобными способами:

1. **Через команду `/report user`:**
   * Начните вводить команду `/report user` в любом текстовом канале.
   * Появится модальное окно, где вы сможете выбрать пользователя из списка и описать ситуацию.
2. **Через меню пользователя (правый клик):**
   * Нажмите правой кнопкой мыши на никнейм пользователя.
   * В появившемся меню выберите `Приложения` -> `Пожаловаться на пользователя.`                  &#x20;
3. **Через меню сообщения:**
   * Нажмите на три точки `(...)` справа от сообщения, которое нарушает  правила.
   * В меню выберите `Приложения` -> `Пожаловаться на сообщение`.

**Заполнение формы жалобы**

После выбора одного из способов появится модальное окно, где необходимо указать:

* **Причина:** Кратко опишите суть нарушения (например, "Оскорбление", "Спам").
* **Подробное описание:** Детально изложите ситуацию. Чем больше подробностей, тем быстрее модераторы смогут принять решение.
* **Вложения (опционально):** Вы можете прикрепить **до 5 изображений** (скриншотов) в качестве доказательств.

**Что происходит после отправки?**

Ваша жалоба будет конфиденциально отправлена в закрытый канал для модераторов. После того как модератор рассмотрит вашу жалобу и вынесет вердикт, вы получите **личное сообщение (DM)** от бота с результатами рассмотрения и комментарием модератора.

***

### Для администраторов

**⚙️ Первоначальная настройка**

Для работы системы необходимо указать, куда отправлять жалобы.

1. Используйте команду `/settings reports`. У вас должны быть права администратора или 5-й уровень доступа.
2. Откроется панель управления. Нажмите на выпадающее меню и выберите **"Канал для жалоб"**.
3. В появившемся меню выберите текстовый канал, который будет доступен только модераторам.

**Дополнительные настройки:**

* **Роль для оповещений:** Вы можете указать роль, которую бот будет упоминать (`ping`) при поступлении новой жалобы.
* **Роли модераторов:** Если вы не используете систему уровней доступа, здесь можно указать роли, которые смогут рассматривать жалобы.

**Процесс рассмотрения жалобы**

1. **Новая жалоба:** Когда поступает новая жалоба, в настроенный канал приходит сообщение в современном формате с полной информацией:
   * Уникальный **ID** жалобы.
   * Кто подал жалобу и на кого.
   * Причина и подробное описание.
   * Галерея прикрепленных изображений.
   * Кнопка **"Рассмотреть"**.
2. **Рассмотрение:**
   * Модератор нажимает на кнопку **"Рассмотреть"**.
   * Открывается модальное окно, где нужно:
     * **Вынести вердикт:** Выбрать один из вариантов (✅ `Подтверждено`, ❌ `Не найдено`, 🗑️ `Спам`).
     * **Написать ответ:** Оставить комментарий, который будет отправлен пользователю, подавшему жалобу.
3. **Завершение:**
   * После отправки формы исходное сообщение с жалобой в канале модераторов **обновляется**: в нем отображается вынесенный вердикт, имя модератора и его ответ. Кнопка "Рассмотреть" исчезает.
   * Пользователь, подавший жалобу, получает DM с результатами.

**Команда для изменения вердикта**

Иногда требуется пересмотреть уже закрытую жалобу. Для этого существует специальная команда.

* **Команда:** `/report change`
* **Параметр:** `complaint-id` (уникальный ID жалобы, указанный в заголовке).
* **Доступ:** Модераторы с 3-м уровнем доступа и выше.

Эта команда снова откроет модальное окно для вынесения вердикта, позволяя изменить решение и обновить информацию по жалобе.

**Сброс настроек**

В панели `/settings reports` есть кнопка с корзиной, которая позволяет полностью сбросить все настройки модуля для вашего сервера (канал, роли и т.д.). Сами жалобы при этом не удаляются.
