# Развлечения

| Команда                                | Описание                                                                                                                                                                                                                                                               | Пример использования                                                                                                                                                               |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/ball <task>`                         | Задайте вопрос магическому шару. Он знает все ответы!                                                                                                                                                                                                                  | `/ball task:Стоит ли мне сегодня лечь спать пораньше?`                                                                                                                             |
| `/random <a> <b>`                      | Выдает случайное число в заданном диапазоне.                                                                                                                                                                                                                           | `/random a:1 b:100`                                                                                                                                                                |
| `/emojify <text>`                      | Преобразует ваш текст в большие буквы из эмодзи.                                                                                                                                                                                                                       | `/emojify text:Привет`                                                                                                                                                             |
| `/ship <user1> [user2]`                | Узнайте, насколько два человека совместимы.                                                                                                                                                                                                                            | `/ship user1:@пользователь1 user2:@пользователь2`                                                                                                                                  |
| `/rps <user_choice>`                   | Сыграйте в "Камень, ножницы, бумага" против бота.                                                                                                                                                                                                                      | `/rps user_choice:камень`                                                                                                                                                          |
| `/tictactoe classic [opponent]`        | Запускает игру в классические крестики-нолики на поле 3x3. Если `opponent` не указан, вы играете против умного ИИ. Если вы укажете другого пользователя, ему будет отправлено приглашение на дуэль. Цель: собрать 3 своих знака в ряд.                                 | <p><strong>Игра против ИИ:</strong><br><code>/tictactoe classic</code><br><br><strong>Вызов другого игрока:</strong><br><code>/tictactoe classic opponent:@пользователь</code></p> |
| `/tictactoe chinese [opponent]`        | <p>Запускает игру в китайские крестики-нолики. Если <code>opponent</code> не указан, вы играете против ИИ. </p><p><strong>Правила:</strong> у каждого игрока может быть не более 3-х фишек на поле. Когда вы ставите четвертую, ваша самая старая фишка убирается.</p> | <p><strong>Игра против ИИ:</strong><br><code>/tictactoe chinese</code><br><br><strong>Вызов другого игрока:</strong><br><code>/tictactoe chinese opponent:@пользователь</code></p> |
| `/ascii <text>`                        | Превращает текст в красивый ASCII-арт.                                                                                                                                                                                                                                 | `/ascii text:VLesnix`                                                                                                                                                              |
| `/image filter <filter_type> [member]` | Применяет один из нескольких классных фильтров к аватару пользователя.                                                                                                                                                                                                 | `/image filter filter_type:Sepia (like an old photo) 🎞️ member:@пользователь`                                                                                                     |
| `/image overlay <overlay> [user]`      | Накладывает на аватар пользователя забавные эффекты.                                                                                                                                                                                                                   | `/image overlay overlay:Wasted (GTA-style) 💔 user:@пользователь`                                                                                                                  |
| `/image animal <animal>`               | Присылает случайное изображение милого животного.                                                                                                                                                                                                                      | `/image animal animal:Fox 🦊`                                                                                                                                                      |
| `/nsfw [tags]`                         | Показывает "пикантную" картинку с rule34. Только для взрослых!                                                                                                                                                                                                         | `/nsfw tags:неко`                                                                                                                                                                  |
