# Браки

**Команды для пользователей**

| Команда                   | Описание                                                                        |
| ------------------------- | ------------------------------------------------------------------------------- |
| `/marry propose <member>` | Предложить другому пользователю вступить в брак. Предложение действует 5 минут. |
| `/marry divorce`          | Расторгнуть текущий брак.                                                       |
| `/marry list`             | Показывает список всех заключенных браков и дату их создания.                   |

**Команды для администраторов**

| Команда                           | Описание                                   |
| --------------------------------- | ------------------------------------------ |
| `/forced marry <user1> <user2>`   | Принудительно поженить двух пользователей. |
| `/forced divorce <user1> <user2>` | Принудительно развести двух пользователей. |

**Особенности**

* **Действия с партнером:** Если вы состоите в браке с пользователем, некоторые RP-команды (например, `/rp choice:Поцеловать`) будут иметь уникальное описание и анимацию. Также становятся доступны эксклюзивные действия, такие как "Нежный поцелуй" или "Танец".
* **Кулдаун:** После развода накладывается 24-часовой кулдаун на заключение нового брака.
* **Ограничения:** Нельзя вступить в брак с самим собой или с ботом.
