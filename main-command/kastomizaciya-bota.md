# Кастомизация бота

Этот модуль дает администраторам возможность изменить серверный профиль VLesnix Guard, сделав его уникальным для вашего сообщества.

**Как это работает?**

С помощью одной простой команды вы получаете доступ к интерактивной панели, где можно:

* **Изменить никнейм:** Дайте боту имя, соответствующее тематике вашего сервера.
* **Установить аватар:** Загрузите собственную иконку профиля.
* **Установить баннер:** Добавьте кастомный баннер для профиля бота.

{% hint style="info" %}
**Примечание:** Для установки баннера боту требуется, чтобы ваш сервер имел **2-й уровень буста**.
{% endhint %}

**Команды**

| Команда      | Описание                                                                                   | Права         |
| ------------ | ------------------------------------------------------------------------------------------ | ------------- |
| `/customize` | Открывает панель управления для изменения ника, аватара и баннера бота на текущем сервере. | Администратор |

**Панель управления**

После ввода команды вы увидите две основные опции:

1. **Настроить бота:** Открывает модальное окно, где вы можете ввести новый никнейм и загрузить файлы для аватара и баннера.
2. **Сбросить настройки:** Полностью убирает все серверные кастомизации и возвращает боту его глобальный (стандартный) профиль.
